# Câmara Municipal - Adelândia

Crie um portal institucional moderno para Câmara Municipal, inspirado nos melhores portais legislativos do Brasil.

O sistema deve possuir:

- Design premium e elegante

- Visual institucional moderno

- Layout responsivo Mobile First

- Modo Claro e Escuro

- Acessibilidade LGPD e WCAG

- Alto desempenho e SEO

- Estrutura modular

Utilizar:

- React

- Next.js

- TypeScript

- Tailwind CSS

- Supabase

- ShadCN UI

Paleta:

Azul institucional

Branco

Cinza claro

Dourado discreto para detalhes

Estilo visual:

- Câmara Federal

- Senado Federal

- Assembleia Legislativa de Goiás

- Portais governamentais modernos

Priorizar:

- Transparência

- Facilidade de navegação

- Elegância

- Confiança institucional

Criar animações suaves.

Adicionar efeitos modernos:

- Glassmorphism leve

- Cards premium

- Hover sofisticado

- Transições suaves
